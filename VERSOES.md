# Versões do site Groove Lab 3D

O site tem duas versões no mesmo arquivo (`index.html`). Para trocar, mude uma linha no começo do arquivo:

```js
const TEMA="natal";   // versão natalina: vermelho, neve, faixa natalina e duende mágico nas abas
const TEMA="oficial"; // versão oficial: azul da marca, sem duende
```

Produtos, preços, avaliações e Pix são os mesmos nas duas versões. Qualquer alteração vale para ambas.

Histórico no Git:
- commit `0526cb0`: último site oficial antes das mudanças de Natal
- commit `ccaa669`: primeira publicação da versão natalina
